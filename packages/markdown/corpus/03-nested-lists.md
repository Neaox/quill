# Nested lists

Source: written for this spike.

- Top level item
  - Second level
    - Third level
      - Fourth level
  - Another second level
- Back to top level

Ordered inside unordered:

- Preparation
  1. Install the toolchain
  2. Clone the repository
  3. Run the setup script
- Execution
  1. Start the server
  2. Open the app

Ordered list with a custom start:

5. Fifth
6. Sixth
7. Seventh

A loose list, where items are separated by blank lines:

- First item.

  A second paragraph inside the first item.

- Second item.

A tight list immediately after:

- one
- two
- three

Mixed ordered nesting:

1. Alpha
   1. Alpha one
   2. Alpha two
2. Beta
   - Beta bullet
   - Another Beta bullet
3. Gamma
