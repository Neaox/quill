# Math and dollars

A formula in a sentence, $E = mc^2$, and another, $\frac{a}{b}$, stay as they were written.

Each of these is a price and not a formula, so none is escaped: from $501 to $2,500 a night, a $5 fee and a $10 fee, or $5 now and $6 later.

A closing dollar before a digit is not one: $x$5 is prose, and so is $ x $ with space inside.

An escaped pair is prose too: \$x\$ and \$5\$.

Formulas in markup: *the $a_i$ term*, **the $\sum_i x_i$ total**, [the $O(n)$ bound](https://example.com), and `$not math$` in code.

- A list item with $\alpha + \beta$ in it.
- A price in a list item, $1,000 for each.
