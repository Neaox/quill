# Channel coverage

Source: written for ADR-037. Each channel is a label the organisation's theme
defines, so :acme[Acme] and :globex[Globex] render as pills in their
own colours. :initech[Initech] is not a label in this theme, so it reads as written.

| Channel | Status |
| --- | --- |
| Acme | :acme[Acme] :ok[Built] `in` Prices and availability, every 20 s. |
| Globex | :globex[Globex] :warn[Partial] Availability only. |
