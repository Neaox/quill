Added: the organisation's theme now applies everywhere it is saved for (ADR-028, "Delivery"). `GET /api/settings/organisation/theme` names the identity and the stylesheet, `GET /api/settings/organisation/theme.css` serves the generated theme with a strong `ETag` of its content hash, and `GET /api/fonts/<file>` serves the faces it names, all three without a session. The application links the stylesheet at its root, writes the identity and the layout attributes on `<html>`, and re-themes every open screen as soon as a theme is saved; the public site embeds the same CSS, writes `data-theme-id` and the layout attributes (`data-rules`, `data-align`) on `<html>` as the application does, and serves `@font-face` for the theme's faces for the first time, so a published page is set in its theme's type rather than a system font. The theme settings screen no longer warns that saving does not apply.
