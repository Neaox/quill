Added: Going offline without noticing no longer stops anyone: the editor says "Offline: your changes are kept on this device" when saves or heartbeats fail (not only when the browser says so), adds after a minute that someone else may be able to edit, and keeps typing local throughout.
Added: On reconnecting, offline changes are merged with whatever was saved meanwhile — block by block, then by word, list item, table row and cell, code line and attribute — and saved with a note ("Merged your offline changes with Sam's"); overlapping changes open a side-by-side view to keep mine, theirs, both, or an edit, and the author whose draft was merged into is told on their next load.
Added: An editor whose lock is held by somebody else keeps its changes and merges them when the lock frees, and "Keep all of mine" remains as an explicit overwrite behind a confirmation.
Changed: Publishing a document whose base moved on uses the same block-and-word merge as drafts, so edits to neighbouring lines of one paragraph now combine; conflicts are still shown with git-style markers.
Changed: The browser's recovery store keeps the draft as last agreed with the server beside the unsent edit, in a versioned row format that still reads rows written by earlier releases.
