Added: The sync job for workspaces that read their documents from an external Git repository (ADR-061): it replays the repository's history as revisions authored by their commit authors, gives each file a lasting id without touching the repository, follows renames, archives removed files, resumes an interrupted replay, and records what failed without emptying the workspace. A workspace read from a repository now also refuses every other write at the content store. Connecting a repository is not available yet.
