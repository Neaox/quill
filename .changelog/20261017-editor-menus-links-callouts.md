Fixed: The slash menu's last items can be scrolled to again. The space kept for the rows not drawn was padding on the list itself, and a box cannot be shorter than its padding, so the list grew past the menu and its end was clipped. The rows' heights are now also fixed in pixels, so a theme's spacing can no longer put the arithmetic out. The arrow keys bring the last item fully into view.
Added: A formatting toolbar over selected words: bold, italic, strikethrough, inline code, link, small print, badge, "Turn into", clear formatting, copy link to section, and comment (disabled until comments exist). Each button shows whether it is on and its shortcut. It appears once a selection is made, never mid-drag, sits above the words or below them when there is no room, and goes on typing, Escape or losing focus. Alt+F10 or Ctrl+Shift+\ moves focus into it. It stands aside in code blocks and tables.
Added: Links can be made and edited. Ctrl+K (Cmd+K) opens a link popover in the editor: paste an address, or type to find a document, which is linked by its id. The popover also changes a link's words, and opens, copies or removes it. A link shows a small card with the same actions when the caret is in it or the pointer rests on it. Global search no longer takes Ctrl+K while you are writing.
Added: A context menu in the writing surface, on right-click, Shift+F10, the context-menu key, or a long press on a phone (as a sheet). It offers what fits what is under the pointer: cut, copy, paste and paste as plain text, formatting and "Turn into" over words; open, edit, copy and unlink over a link; move, duplicate, delete and copy link to section for any block; the table editor's actions in a table cell; replace, alternative text, open and the diagram editor over a picture; language, copy and wrap long lines in a code block; and a callout's type. Shift and right-click still opens the browser's own menu, with its spelling suggestions.
Fixed: GitHub alerts (`> [!WARNING]`) are drawn in the editor as the callouts readers see, with their colour, icon and type, rather than as quotes starting with `[!WARNING]`. `:::callout` blocks are drawn the same way.
Added: A callout's type can be changed from the button on its title line, keeping how it was written: an alert stays an alert and a callout block keeps its attribute block, so only the type word changes. A callout block can have a title of its own, and a quote can become a callout and back.
