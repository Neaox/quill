Changed: Comparing two versions of a document shows the document as readers see it, with added words underlined and tinted, removed words struck through, each announced to screen readers, changed blocks flagged in the margin, moved blocks shown where they went, unchanged stretches folded, and images and diagrams before and after. Tables are compared by row and cell, lists by item, and code by line.
Added: A source view of a comparison shows the Markdown side by side or unified, with line numbers and the changed words picked out, in the theme's code colours.
Added: The comparison view has a summary of what changed, a list of changes and the sections they are in, previous and next change buttons with the `n`/`p` (and `j`/`k`) keys, version pickers showing who published each version, when and why, a swap control, quick choices for the previous version and for the published document against your draft, restore, and a copy link button.
Added: The revisions beside a document offer "Compare versions", and each revision offers a comparison with the one before it.
Changed: `GET /api/documents/:id/diff` is replaced by `GET /api/documents/:id/compare` and `GET /api/documents/:id/compare/source`, which return a structured comparison with no storage paths, revision hashes or Git headers, and accept `to=draft` for an editor.
