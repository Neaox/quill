Changed: pasting a large document is fast and never freezes the tab. Markdown or plain text is read once, straight from the clipboard, and a large paste (more than 16 KB) is parsed in the background while you keep typing; it lands where your cursor was, and if it takes more than 300 ms a quiet "Pasting…" shows where it will appear (Escape cancels it). Code blocks open as the reader shows them and become editable as they come near the screen or when you click into them, so a document with hundreds of code blocks no longer builds them all at once. Pasting a whole document from Google Docs or Word that contains tables now pastes the whole document, rather than only its first table.
