Added: Search has a surface. A command palette opens from the top bar's search field and with Ctrl+K or Cmd+K from anywhere you are signed in: results appear as you type, grouped as "In this workspace" first and then by workspace under "Elsewhere", each with the matched words marked in a snippet and the collection it lives in underneath. The arrow keys move between results and Enter opens one without focus ever leaving the field, and how many results arrived — and how many workspaces they came from — is announced as each answer settles.
Added: A full results page at `/w/<workspace>/search?q=` for the whole answer, with the same grouping and a "Show more" that lengthens the page rather than starting it again. The query lives in the address, so a search can be linked to, shared, reloaded, and stepped out of with the back button.
Added: `CommandPalette` in the design system: a combobox over a grouped listbox in a modal dialog, with the keyboard behaviour and the focus handling a screen reader needs, a result named by its title alone so the arrow keys do not read a paragraph of matched text on every press, and a polite live region for the count. It has a specimen in the design showcase.
Security: Signing out now empties the query cache instead of forgetting only who was signed in, so nothing the previous account read — search results across every workspace it could see, document titles, snippets — is still in memory when somebody else signs in in the same tab.
