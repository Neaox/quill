Fixed: Typing in a long document no longer stalls on every keystroke. The editor used to convert the whole document to Markdown on each keystroke. It now marks the draft unsaved and converts once, when the debounced save is about to go, when the tab is hidden, or when the editor closes. Unknown-label warnings, emoji and required-section markers are now redrawn only for the block that changed. On a 4,100-line runbook a keystroke now takes a median of about 1.4 ms, down from about 22 ms in the test environment. In the browser it was 85 to 120 ms. A guard test fails if a keystroke converts or walks the whole document again, or if it goes over the 16 ms budget.
