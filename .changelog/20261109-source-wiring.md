Added: A workspace can now read its documents from an external Git repository (ADR-061). An instance administrator configures the repository's address, branch, the collections it fills, how much history to replay, whether commit messages are shown and an optional credential held in the secrets store; the first sync starts at once, and a workspace administrator can ask for another with "Sync now" (`POST /api/workspaces/:id/source/sync`). Syncs run in the background, one per repository at a time, without holding up anything else.
Changed: A request that would write a workspace read from a repository is now refused with `403 workspace_read_only` rather than a generic permission error.
