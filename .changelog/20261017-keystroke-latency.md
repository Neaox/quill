Improved: typing in a long document keeps up with you. In a 4,100-line runbook, a keystroke now reaches the screen in about 11 ms instead of 35 to 60 ms. Pressing Enter takes about 90 ms instead of 400 ms. The editor no longer redraws parts of the page you can't see, so find-in-page, screen readers and the caret still see the whole document. Right after a large paste, the table controls no longer freeze the page for most of a second.
