Added: Search works. `GET /api/search?q=` answers with the matches in the workspace you are in first and every other workspace you can read grouped below it, each hit carrying a snippet with the matched spans as offsets, a breadcrumb, and the short key its link is built from. The query language is the one `@quill/search` already parsed — quoted phrases, `-exclusions`, and `title:`, `tag:`, `owner:`, `status:`, `collection:` and `in:` filters — and a misspelled title still finds its document.
Added: A PostgreSQL full-text index (`document_search`) with the weighted columns ADR-010 asks for — title A, headings B, body C — a GIN index over them, and `pg_trgm` for typo tolerance where the extension can be installed; where it cannot, search runs without it rather than refusing to start. Every word you type has to appear; when that finds less than a screenful the search widens to match any of them, and a quoted phrase is never widened past.
Fixed: Resolving what a person may see no longer names every document in a workspace to find the handful of grants they hold. The grants are asked for by principal instead, which is the same answer several times faster, and it lifts a ceiling that made any workspace over about thirty-three thousand documents fail outright — in the flat document list as surely as in search.
Added: Publishing a document indexes it, and renaming one re-indexes it, both from the `DocumentPublished` and `DocumentRenamed` outbox events. Deleting a document removes its entry with it.
Added: `pnpm --filter @quill/server reindex` rebuilds the search index from the content store, for one workspace or the whole instance, and `--render` rebuilds cached bodies alongside it (ADR-034).
Added: `SEARCH_RATE_LIMIT_MAX` gives search its own per-session budget, separate from the much smaller authentication one.
Added: `pnpm --filter @quill/server bench:search` measures search against the 50,000-document budget in quill-plan.md §31, and `--explain` prints the query plan.
Changed: There is now one `SearchIndex` port rather than two. It is declared with the other ports in `@quill/application` in the shape `@quill/search` needs — the parsed query, the mandatory visibility filter, the full ranking profile, and hits that still carry their body text — and `@quill/search` re-exports it.
Security: A search never returns a document the person searching may not read. The permission filter is applied inside the SQL, resolved by the same materialise-and-combine the navigation tree uses (ADR-012), so a denied document is not merely hidden from the results: it is never scored, counted, or paged past. Searches are not audited, because a log of what everybody looked for is a liability rather than a record.
