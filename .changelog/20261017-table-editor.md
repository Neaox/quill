Added: a table editor to match the way tables read. A table looks the same while you write it as when it is read, with its header row, footer, row headers and column alignment. Hover a table, or click into it, to get a grip above each column and beside each row: click a grip to select the row or column, or drag it to move it. A "+" between the grips inserts a row or column exactly there. Drag a border between columns to resize them, with both widths shown as you drag, or drag the table's edge to set its width. It snaps to the text column, wide and full. Under the table, a toolbar turns the header row, header column, footer and caption on and off, aligns columns, inserts and deletes rows and columns, and sets how readers see the table. When a control can't be used, its tooltip says why. Tab and Enter add a row from the last cell. Ctrl+Alt+arrows insert rows and columns, and Alt+arrows move them. Pasting from Excel or Google Sheets makes a clean table: merged cells are split rather than kept as phantom merges, and hidden and empty trailing rows are dropped. Every change undoes in one step.
