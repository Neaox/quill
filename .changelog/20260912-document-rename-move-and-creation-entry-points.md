Added: A document's title can be renamed inline from its header — click it or press F2, Enter saves, Escape cancels, blur saves — and a "Move to…" dialog, reachable from the header and from the tree row's overflow menu, moves it to a different collection or parent with a tree picker that marks the current location and disallows moving a document into its own subtree. Both are visible only to someone with `manage` on the document.
Added: A document can now be created from wherever a person is working, not only the workspace home header: a "New" control above the document tree (present on every workspace and document page), a "+" revealed on each collection, "New child document" on every tree row's overflow menu, and the `c` keyboard shortcut all open the same dialog, preset to the collection or parent they were opened from. The dialog also creates the workspace's first collection inline when it has none, and offers an optional parent-document picker.
Fixed: A document's tree item link now navigates through the router instead of a full page anchor, so clicking it preloads and switches views client-side rather than reloading the app; the tree's "more actions" trigger is a real, keyboard-operable button styled like the rest of the design system instead of a native disclosure standing in for one.
Fixed: The "New document" dialog no longer leaves Create disabled with no visible reason once a collection exists — the destination it was opened for, or the workspace's first collection, is chosen automatically and can still be changed.
