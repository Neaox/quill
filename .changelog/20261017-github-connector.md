Added: link previews have a connector layer, and GitHub is the first connector. A link to a GitHub repository, pull request, issue or code permalink (`blob/<commit>/<path>#L10-L20`) now shows its state (Open, Draft, Merged, Closed) as a lozenge on chips, compact links and cards, and a permalink is drawn as a captioned, numbered code block. Previews are made from `api.github.com` for public content only; a private repository's link stays a plain link, and a preview kept from when a repository was public is dropped once it is private. An administrator can store a read-only token (ideally limited to public repositories) as the secret `connectors/github/token` on the Secrets screen to raise GitHub's rate limit; without one, GitHub is asked anonymously. A GitHub rate limit defers the fetch instead of failing it. A line-range fragment is now part of a link's preview key. The editor's link card shows the status and the first lines of a permalink. The `/bot` page names the services Quill asks through their API. See ADR-042 and `docs/security/review-2026-10-13-link-previews.md`.
