Added: One language registry for code blocks (`@quill/highlight/languages`): every language's name, the fence names and file extensions that mean it, its category and its grammar, read by the reader, the renderer, the copy button, code group tabs and the editor alike.
Changed: Code blocks in the editor are coloured by the reader's own tokenizer and painted the reader's way, through the CSS Custom Highlight API, so every language the reader colours — Go, Rust, Java, C#, Bash, TOML, Dockerfile, Diff and the rest — is coloured while it is written, in the same colours. Where the browser lacks the API the same ranges are drawn as spans.
Changed: A code block's language is chosen in a searchable picker grouped by category, with recently used languages and plain text on offer; Enter or Alt+Down opens it, Escape returns to the code, and choosing is one undoable step that recolours the block at once. It replaces the browser's suggestion list, which did not appear reliably inside the editor.
Fixed: Code no longer reads as selected text under forced colours, in the reader or the editor.
