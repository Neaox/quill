Added: A document can be shared with somebody who has no account. A link covers that document, or that document and everything nested under it, carries a view role and an optional expiry, and can be revoked — closing on the very next request. The token is 256 random bits, only its SHA-256 is stored, it is shown to its creator exactly once, and it never appears in a log line, a response body, or an audit row (`docs/architecture/api-contract-share-links.md`). Creating, listing and revoking need `manage` on the document; reading through a link needs no account, shows the published body and nothing else about the organisation, is `noindex`, and is rate limited per address. Unknown, expired, revoked, out of scope, unpublished, and a document the platform cannot place in its own tree are all answered identically, so a token cannot be probed for. Every use is audited, with the source address recorded as a digest. The server half only: the share dialog and the share-link page come with the web work.
Added: `SHARE_LINKS=on|off` (default on) decides whether an organisation has share links at all. Turning it off refuses new links and closes existing ones on their next use, because the policy is asked on every use rather than cached. It moves to the organisation's settings when the settings store lands.
Fixed: Moving a document into another collection without naming a parent now lifts it to the top of the destination instead of leaving its parent behind in the old collection. A document whose parent is in another collection has no place in the permission tree, so every request for it failed — including the one that would have moved it back.
Security: A 404 for an unknown route no longer echoes the URL that was asked for verbatim, so a mistyped or trailing-slash share link cannot hand its token back in the response body.
