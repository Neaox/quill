Added: A public site's search results page now says where each result sits (the pages above it) and when it was published, as a machine-readable `<time>`, and the box keeps what was typed so it can be amended.
Added: Public search pages through its results. Twenty at a time, with a "More results" link that carries the query on; the page says "Showing the first 20 results" rather than claiming a total it has not counted, and says "N results" only when the answer is complete. A cursor that was not issued by the search starts again from the top instead of showing an error.
Fixed: A public search that could not be run no longer pretends nothing matched. A query the parser cannot read (an unclosed quote) shows the parser's own explanation, and a query of only exclusions says a search needs a word or phrase to look for. "Nothing matched" now suggests different words, fewer words, or another spelling.
Added: A public site's search has a budget of its own, counted apart from page views, 30 a minute per address by default (`PUBLIC_SEARCH_RATE_LIMIT_MAX`). A page is read from a cache and a search is a query against the index, so the one request on the public surface whose cost a stranger chooses is no longer counted with the rest. It is counted before the site is looked up, so being refused tells nobody which site addresses exist.
Changed: A public search that was just answered is answered again from memory for a few seconds, and forgotten the moment something is published, renamed, moved or unpublished. These have a bound of their own, so a stranger's questions cannot push out the pages readers are on.
