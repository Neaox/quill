Fixed: The Playwright journeys run as their own instance beside `pnpm dev`, never on top of it: an API server on `:3100` against its own `quill_e2e` database (emptied before every run) and its own content store, and a web app on `:5174`. Reusing a developer's running servers made every seeded document open as "nothing published yet", because the seed and the server were reading different content stores, and left a workspace per test in the development database.
Added: `pnpm --filter @quill/server db:reset` empties the configured database (creating it first when it is missing) so the next start migrates it from nothing. It refuses a database whose name does not end in `_e2e` or `_test` unless `DATABASE_RESET_ALLOW=1`, and never runs under `NODE_ENV=production`.
