Changed: The lint rule against awaiting inside a loop now reports only loops whose iterations are independent, so it is quiet for the many places that are sequential on purpose (migrations, consumers run in order, stateful streams) and errors in production code where a loop could be run in parallel. A counter or total that the loop only adds to, and a repository asked once per item through a transaction, no longer hide such a loop.
Changed: Listing grants for many scopes queries its chunks together, and the refusal for an attachment still in use checks the documents that hold it together, instead of one after another.
Fixed: The label editor and the emoji editor no longer start from a new empty list and map on every render.
