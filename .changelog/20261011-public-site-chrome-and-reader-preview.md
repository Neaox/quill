Changed: The public site has the chrome of a polished documentation portal, drawn entirely from the organisation's theme. A sticky, translucent header carries the organisation's lockup and a System / Light / Dark switch that remembers the reader's choice (the same one the app remembers) and applies it before the first paint; the documents sit down the side as one folding section per collection with the current page marked, "On this page" lists the second- and third-level headings once there are three, and the collection's name sits above the title unless the author wrote an eyebrow of their own. Under 1200 pixels the contents give way, and under 960 the documents fold into a card above the page. The site still runs no inline script: the switch is one small same-origin file, addressed by its own hash like the stylesheet, and without scripts the switch is simply absent and the page follows the system.
Added: Preview a document as its readers will see it. `GET /preview/d/<document>` renders any document you may read through the public site's own templates, with the navigation the site would build, whether or not anything is published — marked by a small floating "Preview" pill that says whether the page is live on the web and leads back to the document. It is never indexed and never cached publicly, and a document you may not read answers exactly as a missing one does. `PreviewLink` in the web app opens it.
Fixed: The public stylesheet's address now changes when the site's own CSS changes, not only when the theme does, so a release that restyles the site is not hidden behind a year of `immutable` caching. A wide table on a public page now scrolls inside its own width instead of widening the page on a phone.
