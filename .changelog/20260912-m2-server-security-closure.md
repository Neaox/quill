Security: Sign-up, magic-link and password-reset requests now cost the same whether or not the address has an account. Sign-up hashes on both branches, an unknown address still mints and hashes a token, and mail is queued through the outbox instead of being delivered on the request path, so the latency no longer answers "is this person registered here?".
Security: Magic-link, verification and reset links now carry their token in the URL fragment rather than the query string, so it never reaches a server log, browser history, or a `Referer` header. Consuming a link needs the browser that asked for it — bound by a short-lived `__Host-` cookie — or an explicit confirmation, so a mail scanner or link-preview bot following the link cannot spend it.
Security: A lock is no longer a substitute for a permission check. `edit` is re-resolved on every heartbeat and every draft write, and an editor whose access has been withdrawn is refused and has their lock released rather than editing until they close the tab.
Security: `PATCH /api/documents/:id` now validates where a document is being moved to — the collection has to be in the same workspace, the parent has to be in the destination collection, and nothing may become its own ancestor — and requires `manage` at the destination as well as at the source. `documents.parent_id` gained a foreign key, so a parent that does not exist can no longer make a document permanently unresolvable.
Security: The outbound HTTP client now connects to the address it checked, instead of letting the connection resolve the hostname a second time (DNS rebinding). IPv6 addresses are parsed to their sixteen bytes, so `::ffff:7f00:1`, NAT64 and 6to4 spellings of a private address are refused, and the response size cap is applied while the body arrives rather than after it has all been read.
Security: Email addresses are normalised (trimmed and lower-cased) everywhere the platform looks one up or stores one, with a unique index on `lower(email)` behind it, so one mailbox is one account however it is typed.
Security: The public magic-link endpoint issues sign-in links only, and no longer creates an account for an unknown address — it was a way to make accounts, and to squat somebody else's address before they signed up. Reset and sign-in links now share one rate-limit budget per account and purpose across every route that can send them, and the endpoints that consume a token are rate limited by source address.
Security: The API description at `/api/openapi.json` is no longer served in production. It is the route map, and publishing it unauthenticated is reconnaissance handed over whether or not a browser renders it.
Security: The breached-password check now falls back to a bundled list of the passwords every corpus knows when the remote service cannot be reached, instead of silently allowing anything for the length of the outage.
Security: The server refuses to boot under `NODE_ENV=production` when `DATABASE_URL` is unset or the mail driver is the one that logs live links to stdout, and the seed refuses to run there without an explicit opt-in.
Security: `SECURE_COOKIES=false` is ignored on an https instance (with a warning) rather than stripping `Secure` from the session cookie, and a `SESSION_COOKIE_NAME` without the `__Host-` prefix is refused on a secure instance.
Security: Password hashing is now a registry of schemes keyed by the identifier the stored hash carries, so a future algorithm change is a new file rather than a migration; a hash written by a scheme this build no longer carries fails closed.
Added: `TRUST_PROXY` says what is in front of the server — a hop count, or the addresses and CIDR ranges to believe. Without it, `X-Forwarded-For` and a caller-supplied `X-Request-Id` are ignored, so neither can be used to spend somebody else's rate-limit budget or to write arbitrary text into the logs.
Fixed: Signing out, or having a session revoked or rotated, now releases the document locks that session held, instead of leaving the document locked for a further minute.
Fixed: Signing out actually clears the session cookie: the deletion now carries the same attributes the cookie was set with, which a browser requires before it will honour it.
Fixed: An outbox event that has failed too many times is set aside with its last error rather than retried for ever, and every event type something emits now has a consumer, so a type nothing handles cannot accumulate.
Fixed: Expired sessions and spent magic-link tokens are swept periodically instead of accumulating for the life of the instance.
Fixed: Acquiring a document lock at the moment another session releases it now answers "available" after a retry rather than failing with a server error.
