Fixed: Taking away public access now takes effect on the next request. A grant written or revoked, a document or collection deleted, or a collection unpublished used to reach the public site's cache only when its fifteen-second time to live ran out, so a page whose access had been revoked could still be read, and found by search, for a few seconds. The cache is now told when the change commits.
Added: An event system with one definition per event (`defineEvent`), one way to emit it (`tx.events.record`, which writes the outbox row and announces it once the transaction commits and never if it rolls back), and an in-process `EventBus` of observers for reactions that are safe to lose, such as a process's own caches (ADR-052). The outbox is unchanged as the durable record. New events: `GrantCreated`, `GrantRevoked`, `DocumentDeleted` and `CollectionDeleted`.
Changed: The public site's cache is cleared by a bus subscriber instead of by outbox consumers, because an outbox event is claimed by one poller and a cache has to be told in the process that holds it. A magic-link mail event carries its token and is never announced on the bus. Both composition roots register one shared list of outbox consumers, and a test pins that every event type Quill emits has one.
