Fixed: Saving a document from the editor no longer turns GitHub alerts (`> [!NOTE]`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`) into plain quotes: the marker is written unescaped and stays on its own line when the body's soft wraps collapse.
Fixed: The first save of a document from the editor leaves it as it was written, but for its soft wraps: emphasis markers, two-space hard breaks, table delimiter rows and unchanged table rows, unquoted directive attributes, blank lines between blocks and inside container fences, ordered list numbers, and characters such as `~`, `_`, `&`, `[` and `#` that need no escape are no longer rewritten.
