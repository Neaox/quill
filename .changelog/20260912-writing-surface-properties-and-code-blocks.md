Changed: The writing surface no longer shows a document's front matter as raw YAML. A document's metadata is a properties strip above the body instead — closed, one line of facts (status, type, owners, tags as chips); open, the fields those facts come from, the questions a template declares, and every other key the document carries, listed read-only so nothing is hidden or lost. An edit writes the whole record back through the draft, so autosave and publish carry it and unknown fields, key order and comments survive the round trip. A document's owners are visible without opening anything: they are part of the closed strip's readout, which is where the header's empty `owner: —` used to stand.

Changed: Code blocks in the editor wear the same frame as the reading surface's: a caption strip over the code, the same tokens, radius and borders, and the same metrics. The language control offers every grammar the reading surface can colour, under its canonical name, with a "Plain text" option and no internal placeholders; a block carries a copy action; the line-number gutter is aligned to the reading measure; the focus ring is the design system's; and a `:::wide` block keeps its width while it is written. CodeMirror's colours are checked against the theme's token classes, so a class the reading surface colours and the editor does not now fails the build.

Fixed: The writing surface takes the reading surface's vertical rhythm. Blocks were spaced by margins of their own and headings, tables, callouts and code blocks sat at distances no reading surface uses; the editor's grid is now the prose root, so a paragraph, a heading and a table are the same distance apart while they are written as when they are read.
