# Changelog

All notable changes to this project are documented here. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project follows [Semantic Versioning](https://semver.org/) from its first
released version onward.

## Unreleased

Pending changes are tracked as fragment files in
[`.changelog/`](.changelog/README.md), not written here directly. Run
`pnpm changelog:release <version>` to assemble them into a dated section
below.
