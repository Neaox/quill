Technical design

Authentication architecture

How platform APIs issue, verify, and revoke access tokens, and what every service must do with them.

Every request to a platform API carries a short-lived access token. Services never validate tokens themselves; they call the gateway, which holds the signing keys and the revocation list. This document is the contract between the identity service and everyone who depends on it.

01Token flow

A client exchanges credentials for a token pair at POST /auth/token. The access token lives for fifteen minutes; the refresh token for thirty days and is rotated on every use, so a stolen refresh token is detected the moment the legitimate client rotates it.

NoteTokens issued before a key rotation stay valid until they expire. Services must accept two signing keys during the fifteen-minute overlap.
