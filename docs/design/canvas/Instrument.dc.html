Authentication architecture

How platform APIs issue, verify, and revoke access tokens, and what every service must do with them.

type=technical-designreview=180dlast-reviewed=2026-08-15

Every request to a platform API carries a short-lived access token. Services never validate tokens themselves; they call the gateway, which holds the signing keys and the revocation list.

#Token flow

A client exchanges credentials for a token pair at POST /auth/token. The access token lives for fifteen minutes; the refresh token for thirty days and is rotated on every use.

note
Tokens issued before a key rotation stay valid until they expire. Services must accept two signing keys during the overlap.

export async function verify(token: string): Promise<Claims> {
  const result = await gateway.introspect({ token })
  if (!result.active) throw new TokenRevoked(result.reason)
  return result.claims
}
