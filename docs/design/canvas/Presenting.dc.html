Getting started

Authentication

Every request is authenticated with a bearer token. This guide shows how to create one, how long it lasts, and how to rotate it without downtime.

Create a token

1

Open Settings, then API keys, and choose the workspace the key belongs to. Keys are scoped to one workspace.

2

Pick a role. viewer reads published documents; editor can also create drafts and publish.

3

Copy the key once. It is shown a single time and stored hashed.

Use it

Send the key as a bearer token. Every response carries the revision of the document it came from, so a client can tell exactly what it read.

curl https://docs.acme.dev/api/documents/018f4c1e \

Rotate without downtime

Create the new key first, deploy it, then revoke the old one. Both keys are valid during the overlap, so nothing fails while the deploy rolls out.
