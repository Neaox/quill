# Setting up your mobile development environment

You need a Mac to build the iOS app and any machine for Android. Budget about 90 minutes, most of it downloads. Ask in `#mobile-eng` for access to the Apple developer team and the Sentry project; both need approval from Jonas Weber.

## Install the tools

Node and pnpm versions are pinned in the repository, so use a version manager:

:::code-group
```bash [macOS]
brew install fnm watchman cocoapods
xcode-select --install
fnm install && corepack enable
pnpm install
cd apps/skiff/ios && pod install
```
```bash [Linux]
curl -fsSL https://fnm.vercel.app/install | bash
fnm install && corepack enable
pnpm install
sudo apt install openjdk-17-jdk
```
```bash [Windows]
winget install Schniz.fnm Microsoft.OpenJDK.17
fnm install; corepack enable
pnpm install
```
:::

Install Android Studio, then the Android 15 SDK and a Pixel 6a emulator. Set `ANDROID_HOME` as the installer suggests.

## Run it

```bash
pnpm --filter skiff start          # Metro bundler
pnpm --filter skiff ios            # simulator, macOS only
pnpm --filter skiff android        # emulator or a connected phone
```

The app points at the staging API by default. Sign in with your `@acme.example` account. If the build fails with a Pods or Gradle error, run `pnpm --filter skiff clean` before you ask for help; it fixes most first-day problems.
