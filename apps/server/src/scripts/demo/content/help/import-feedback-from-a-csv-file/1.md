# Import feedback from a CSV file

If your feedback lives in a spreadsheet, a survey export or another tool, you can bring it into Tidepool in one go. Each row of the file becomes one piece of feedback in your **Inbox**.

## Prepare your file

Save the file as **CSV UTF-8**. In Excel, choose **File > Save As** and pick **CSV UTF-8 (Comma delimited)**; in Google Sheets, choose **File > Download > Comma Separated Values**. The first row must contain column headings. A file can be up to 10 MB and 5,000 rows; split bigger exports into several files.

:::table[Columns Tidepool understands]{width=wide}
| Column | Required | What to put in it |
| :----- | :------- | :---------------- |
| `feedback` | Yes | The words the customer used. Up to 10,000 characters. |
| `source` | No | Where it came from, such as Survey or Interview. Defaults to CSV import. |
| `customer` | No | The company or person's name. |
| `email` | No | The customer's email address, used to link their other feedback. |
| `created_at` | No | When they said it, as `2026-09-30`. Defaults to the time of import. |
| `tags` | No | Labels separated by semicolons, such as `billing;mobile`. |
:::

Columns with other names are fine. You choose what to do with them in the next section.

## Import the file

1. Open **Feedback > Import**.
2. Select **Upload CSV** and choose your file, or drop it onto the page.
3. Check the **Column mapping**. Tidepool matches headings by name; for anything it missed, choose the right field from the drop-down, or **Ignore this column**.
4. Select **Preview** to see the first 20 rows as they will appear.
5. Select **Import**.

Large files import in the background. You can close the page; we email you when it finishes.

> [!WARNING]
> Rows that already exist are skipped. We treat two rows as the same if they have the same `feedback` text and `email` within 90 days. Your import summary says how many were skipped.

## If something goes wrong

Tidepool checks every row before it imports anything. If a row is wrong you see a message such as `Row 14: created_at must be a date` and nothing is imported until you fix the file and upload it again. The most common causes are dates written as `30/09/2026`, a missing `feedback` value, and a comma inside a cell that is not wrapped in quotation marks.

:::callout[Free plan limit]{type=info}
Free workspaces hold up to 1,000 pieces of feedback. If an import would go over, we import nothing and tell you how many rows you have room for. See [Change your plan](doc:Change your plan) to raise the limit.
:::
