# Connect Zendesk

Connect Zendesk and Tidepool turns the tickets you choose into feedback automatically, with the customer, the ticket link and the date already filled in. You need a Zendesk administrator account and a Tidepool Admin role. The integration is available on the Team, Business and Enterprise plans.

## Before you start

Decide how you want to pick tickets. Most teams add a tag in Zendesk, such as `tidepool`, to the tickets that contain a feature request. Only tagged tickets are imported, so private conversations stay private. If you would rather import everything, you can, but tagging is easier to keep tidy.

## Connect your account

1. In Tidepool, open **Settings > Integrations** and select **Zendesk**.
2. Select **Connect Zendesk**.
3. Enter your Zendesk subdomain. If you sign in at `harbourview.zendesk.com`, the subdomain is `harbourview`.
4. Select **Continue**. Zendesk asks you to sign in and approve access. Select **Allow**.
5. Back in Tidepool, under **Which tickets should we import?**, choose **Tickets with a tag** and type your tag.
6. Choose what happens to the ticket's first message and any later customer replies, then select **Save and start import**.

Tidepool imports the last 90 days of matching tickets first, then checks Zendesk every 15 minutes. Imported items appear in your **Inbox** with the source **Zendesk**.

## What gets imported

For each ticket we bring in the subject and the customer's messages as one piece of feedback, the requester's name and email, the ticket's created date, and a link back to the ticket. We do not import agent replies, internal notes or attachments.

> [!WARNING]
> Disconnecting stops new tickets arriving, and the feedback already imported stays in Tidepool. Removing the Tidepool app inside Zendesk has the same effect, but it also breaks the ticket links until you reconnect.

## Troubleshooting

- If you see **Zendesk rejected the connection**, check that the subdomain has no `https://` or `.zendesk.com` and that you are signed in to Zendesk as an administrator.
- If tickets are missing, check that the tag is spelled exactly the same in both places; tags are lowercase in Zendesk.

Still stuck? Read [Why isn't my feedback appearing?](doc:Why isn't my feedback appearing?) for a full checklist.
