# Embed the feedback widget

The Tidepool widget adds a **Feedback** button to your website or web app. Visitors select it, type a message, and it lands in your **Inbox** with the page address and browser attached. There is nothing to install: you add one snippet of JavaScript.

## Get your snippet

1. Open **Settings > Widget**.
2. Choose where the button sits (**Bottom right**, **Bottom left** or **Side tab**) and pick a colour that suits your site.
3. Choose whether visitors must give an email address. Leaving it optional gets more responses; requiring it makes follow-up easier.
4. Copy the snippet shown under **Install**.

## Add it to your site

Paste the snippet on every page where you want the button, just before the closing `</body>` tag. Your workspace ID is already filled in.

```js title="Widget snippet"
window.tidepoolConfig = {
  workspace: "ws_7h3k9qf2",
  position: "bottom-right",
  requireEmail: false,
}

const script = document.createElement("script")
script.src = "https://widget.tidepool.app/v1/widget.js"
script.async = true
document.head.append(script)
```

The script is about 18 KB, loads after your page and does not block it. If your site sets a Content Security Policy, allow `https://widget.tidepool.app` under both `script-src` and `connect-src`.

## Identify signed-in users

If your visitors are already logged in, pass their details so they do not have to type them again:

```js
window.tidepoolConfig.user = {
  email: "dana@lantern.example",
  name: "Dana Okafor",
  company: "Lantern Logistics",
}
```

Set this before the script loads. We use it only to attach feedback to the right customer.

## Check that it works

Open your site in a new private window; you should see the button within a couple of seconds. Send a test message such as "Test from the widget" and look for it in **Feedback > Inbox**, where the source is **Widget**. You can delete it afterwards.

:::callout{type=note}
The button only appears on domains listed under **Settings > Widget > Allowed domains**. If you see nothing, add your domain there, including `www.` if you use it. Wildcards such as `*.northwind.example` are fine.
:::

If a message is sent but does not show up, work through [Why isn't my feedback appearing?](doc:Why isn't my feedback appearing?).
