# Typography

Tideline uses one family, Inter, in four weights, set on a type scale defined in rem so that it follows the reader's browser setting. One rem is 16px unless the reader has changed it, and they sometimes have. Never set font sizes in px in product code.

## Families

| Token | Value | Use |
| :---- | :---- | :-- |
| `--font-sans` | `"Inter", system-ui, -apple-system, "Segoe UI", sans-serif` | All interface text |
| `--font-mono` | `"JetBrains Mono", ui-monospace, "SFMono-Regular", Menlo, monospace` | Code, IDs, API keys |

Inter is served as a variable font (weights 400 to 700) from our own domain, with `font-display: swap`. The fallback stack is metric-adjusted so the layout shifts by less than 0.01 CLS when the web font arrives.

On Skiff, iOS uses San Francisco and Android uses Roboto. The scale below applies; the family does not. Dynamic Type and Android font scaling are honoured up to 200%.

## The scale

| Token | Size | Line height | Weight | Use |
| :---- | ---: | ----------: | -----: | :-- |
| `--font-size-xs` | 0.75rem (12px) | 1rem | 500 | Badges, captions, table footers |
| `--font-size-sm` | 0.875rem (14px) | 1.25rem | 400 | Table cells, helper text, secondary copy |
| `--font-size-md` | 1rem (16px) | 1.5rem | 400 | Body text, form fields |
| `--font-size-lg` | 1.125rem (18px) | 1.75rem | 500 | Lead paragraphs, card titles |
| `--font-size-xl` | 1.5rem (24px) | 2rem | 600 | Page section headings (h2) |
| `--font-size-2xl` | 2rem (32px) | 2.5rem | 600 | Page titles (h1) |
| `--font-size-3xl` | 2.5rem (40px) | 3rem | 700 | Marketing and empty-hero headings only |

Line heights are multiples of 4px so text sits on the same grid as everything else in [Spacing and layout](doc:Spacing and layout).

## Rules of use

- **One h1 per page**, and heading levels never skip. Choose the level for the document's structure, then style it with the size token you want; do not pick `h4` because it looks right.
- **Line length** is 45 to 75 characters for reading text. Use `max-width: 65ch` on prose containers.
- **Body text is 16px** on forms and articles. Dense tables may drop to `--font-size-sm`; nothing the user must read goes below `--font-size-xs`.
- **Weights**: 400 for reading, 500 for emphasis and labels, 600 for headings. Use 700 only at `--font-size-3xl`. Do not fake bold with `text-shadow`.
- **Do not use all caps** for sentences. An all-caps eyebrow label of three words or fewer at `--font-size-xs` with `letter-spacing: 0.04em` is fine.
- **Numbers in tables** use `font-variant-numeric: tabular-nums` and are right-aligned so that digits line up.

## In code

```css title="components/prose.css"
.prose {
  font: 400 var(--font-size-md) / 1.5rem var(--font-sans);
  max-width: 65ch;
  color: var(--color-text);
}

.prose h2 {
  font: 600 var(--font-size-xl) / 2rem var(--font-sans);
  margin-block: var(--space-8) var(--space-3);
}
```

## Accessibility notes

Text must reflow at 320px wide and survive a 200% text zoom without clipping (WCAG 1.4.4 and 1.4.10). Do not fix the height of a container that holds text; use `min-height`. Links in running text are underlined, because colour alone is not enough to identify them.
