# Colour

Tideline colour is a small set of scales exposed as CSS custom properties. Use the semantic tokens in product code. The raw scale tokens exist so the semantic ones can be defined, not so you can pick a shade you like.

## Accent

The accent is a deep teal. It is used for primary actions, links, selected states and focus rings, and nowhere else.

| `--color-accent-100` | `#C5ECEC` | 1.3:1 |
| `--color-accent-300` | `#6CCFD0` | 1.8:1 |
| `--color-accent-500` | `#0F7C84` | 5.0:1 |

## Status

| Token | Hex | Contrast on white |
| :---- | :-- | ----------------: |
| `--color-success-600` | `#1F7A45` | 5.4:1 |
| `--color-warning-600` | `#8A5A00` | 5.9:1 |
| `--color-danger-600` | `#C02B2B` | 5.8:1 |
| `--color-info-600` | `#1F5FBF` | 6.1:1 |

:::callout[Colour never works alone]{type=important}
Every status needs an icon or a word as well as a hue. About 1 in 12 men have some colour vision deficiency, and a red badge next to a green one can look identical. See WCAG 1.4.1 Use of Color.
:::

## Choosing a token

Components read semantic tokens, which point at the scale:

```css title="tokens/semantic.css"
:root {
  --color-text: var(--color-neutral-900);
  --color-text-muted: var(--color-neutral-500);
  --color-link: var(--color-accent-500);
  --color-link-hover: var(--color-accent-600);
  --color-border-control: var(--color-neutral-400);
  --color-focus-ring: var(--color-accent-500);
}
```

## Dark theme

The dark theme remaps the semantic tokens; components do not change. Backgrounds start at neutral-900 (`#151A23`), and the text and accent pairings below are measured against it.

| Role | Hex | Contrast on `#151A23` |
| :--- | :-- | --------------------: |
| Body text | `#EBEEF2` | 15.1:1 |
| Muted text | `#9AA6B8` | 7.1:1 |
| Link and accent | `#2FB3BC` | 6.9:1 |
| Danger | `#FF7B7B` | 7.0:1 |
| Success | `#3FBF7A` | 7.4:1 |

## Contrast rules

Body text needs 4.5:1 against its background (WCAG 1.4.3). Large text, which is 24px or 18.66px bold and above, needs 3:1. Accent-500 was `#1A8A92` until October 2026, which measured 4.1:1 on white and failed for body-size links. It is now `#0F7C84` at 5.0:1.

Borders of inputs, checkboxes and other controls need 3:1 against the surface (WCAG 1.4.11 Non-text Contrast), which neutral-400 meets at 3.2:1. Neutral-200 is for dividers and card edges only, since it measures 1.4:1 and must never be the sole cue that a control exists.

Check any new pairing against the [Accessibility checklist](doc:Accessibility checklist), and see [Buttons](doc:Buttons) for how these tokens are applied to actions.
