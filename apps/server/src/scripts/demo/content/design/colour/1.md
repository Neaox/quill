# Colour

Tideline colour is a small set of scales exposed as CSS custom properties. Use the semantic tokens in product code. The raw scale tokens exist so the semantic ones can be defined, not so you can pick a shade you like.

## Accent

The accent is a deep teal. It is used for primary actions, links, selected states and focus rings, and nowhere else.

| Token | Hex | Contrast on white |
| :---- | :-- | ----------------: |
| `--color-accent-50` | `#E8F7F7` | 1.1:1 |
| `--color-accent-100` | `#C5ECEC` | 1.3:1 |
| `--color-accent-300` | `#6CCFD0` | 1.8:1 |
| `--color-accent-500` | `#1A8A92` | 4.1:1 |
| `--color-accent-600` | `#0B666D` | 6.7:1 |
| `--color-accent-700` | `#0A5259` | 8.9:1 |
| `--color-accent-900` | `#062E33` | 14.5:1 |

## Status

| Token | Hex | Contrast on white |
| :---- | :-- | ----------------: |
| `--color-success-600` | `#1F7A45` | 5.4:1 |
| `--color-warning-600` | `#8A5A00` | 5.9:1 |
| `--color-danger-600` | `#C02B2B` | 5.8:1 |
| `--color-info-600` | `#1F5FBF` | 6.1:1 |

:::callout[Colour never works alone]{type=important}
Every status needs an icon or a word as well as a hue. About 1 in 12 men have some colour vision deficiency, and a red badge next to a green one can look identical. See WCAG 1.4.1 Use of Color.
:::

## Choosing a token

Components read semantic tokens, which point at the scale:

```css title="tokens/semantic.css"
:root {
  --color-text: var(--color-neutral-900);
  --color-text-muted: var(--color-neutral-500);
  --color-link: var(--color-accent-600);
  --color-border-control: var(--color-neutral-400);
  --color-focus-ring: var(--color-accent-500);
}
```

## Contrast rules

Body text needs 4.5:1 against its background (WCAG 1.4.3). Large text, which is 24px or 18.66px bold and above, needs 3:1. The accent-500 on white is 4.1:1, so it may be used for a focus ring and for large text, but never for body-size links. Use accent-600.

Check combinations in the [Accessibility checklist](doc:Accessibility checklist) before adding a new pairing.
