# Spacing and layout

Every gap, padding and size in Tideline sits on a 4px base unit. Spacing tokens are named by their multiple of that unit, so `--space-4` is 4 × 4px = 16px. Use a token, not a number: a padding of 13px is a defect even if it looks right on your monitor.

## Spacing scale

::::wide
:::table[Spacing tokens]{caption=bottom}
| Token | rem | px | Typical use |
| :---- | --: | --: | :---------- |
| `--space-1` | 0.25rem | 4 | Icon to label gap |
| `--space-2` | 0.5rem | 8 | Gap between related controls; badge padding |
| `--space-3` | 0.75rem | 12 | Input padding (vertical), list item gap |
| `--space-4` | 1rem | 16 | Card padding, default stack gap |
| `--space-5` | 1.25rem | 20 | Dialog padding on small screens |
| `--space-6` | 1.5rem | 24 | Gap between form fields |
| `--space-8` | 2rem | 32 | Gap between page sections, dialog padding |
| `--space-12` | 3rem | 48 | Page header bottom margin |
| `--space-16` | 4rem | 64 | Top of a marketing section |
:::
::::

Proximity carries meaning. Items that belong together sit 8px apart or closer; separate groups sit at least 24px apart. If a stack has the same gap everywhere, nothing reads as grouped.

## Breakpoints

Tideline is designed mobile first. Styles with no query apply to the narrowest screens, and each breakpoint adds to them.

| Token | Min width | Columns | Gutter | Side margin |
| :---- | --------: | ------: | -----: | ----------: |
| `--bp-sm` | 40rem (640px) | 4 | 16px | 16px |
| `--bp-md` | 48rem (768px) | 8 | 24px | 24px |
| `--bp-lg` | 64rem (1024px) | 12 | 24px | 32px |
| `--bp-xl` | 80rem (1280px) | 12 | 32px | auto |

Content is capped at 80rem (1280px) and centred. Reading text has its own cap of `65ch`, described in [Typography](doc:Typography).

## Layout primitives

Prefer the layout components over ad-hoc flexbox. They apply the tokens consistently.

- `Stack` places children in a column with a single gap token.
- `Cluster` wraps inline items, such as filters or tags, with the same gap in both directions.
- `Sidebar` puts a 16rem (256px) navigation beside content and collapses below `--bp-md`.

```ts title="Filters.tsx"
import { Cluster, Stack } from "@tideline/react"

export function Filters({ children }: { children: React.ReactNode }) {
  return (
    <Stack gap="6">
      <h2>Filters</h2>
      <Cluster gap="2">{children}</Cluster>
    </Stack>
  )
}
```

## Touch and pointer targets

Interactive elements are at least 24 × 24 CSS pixels on the web (WCAG 2.5.8), and we aim for 32px in dense tables. On Skiff the minimum is 44 × 44pt on iOS and 48 × 48dp on Android. A smaller visual control, such as a 16px checkbox, gets its hit area from padding rather than from the glyph itself.

## Elevation and radius

Radius tokens are `--radius-sm` 4px for inputs and buttons, `--radius-md` 8px for cards and `--radius-lg` 12px for dialogs. Shadows are used only to show that something floats above the page (menus, dialogs, toasts); cards separate with a 1px `--color-neutral-200` border instead.
