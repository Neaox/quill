# Getting started with the Tidepool API

The Tidepool API gives you programmatic access to the feedback, themes and roadmap items in your workspace. It is a JSON REST API served over HTTPS at `https://api.tidepool.example/v2`. This guide takes you from nothing to a successful request in about five minutes.

## Before you begin

You need a Tidepool workspace on any plan and the **Admin** role, which is required to create tokens. The examples use `curl` and the official SDKs for TypeScript, Python and Go. Install whichever you prefer from [SDKs and libraries](doc:SDKs and libraries).

## Make your first request

1. **Create a token.** In Tidepool, open **Settings → API → Tokens**, choose **New token**, name it `local-dev` and grant the `feedback:read` scope. Copy the token straight away: it is shown once and begins with `tp_live_`.
2. **Keep it out of your code.** Export it as an environment variable:

   ```bash
   export TIDEPOOL_TOKEN="tp_live_9fQ2xK7mVb3LrTn8"
   ```

3. **List some feedback.** Ask for the two most recent items:

   :::code-group
   ```bash [curl]
   curl "https://api.tidepool.example/v2/feedback?limit=2" \
     -H "Authorization: Bearer $TIDEPOOL_TOKEN"
   ```
   ```ts [TypeScript]
   import { Tidepool } from "@tidepool/sdk"

   const tidepool = new Tidepool({ token: process.env.TIDEPOOL_TOKEN })
   const page = await tidepool.feedback.list({ limit: 2 })
   console.log(page.data.map((item) => item.body))
   ```
   ```py [Python]
   import os
   from tidepool import Tidepool

   client = Tidepool(token=os.environ["TIDEPOOL_TOKEN"])
   page = client.feedback.list(limit=2)
   for item in page.data:
       print(item.body)
   ```
   ```go [Go]
   client := tidepool.NewClient(os.Getenv("TIDEPOOL_TOKEN"))
   page, err := client.Feedback.List(ctx, &tidepool.FeedbackListParams{Limit: 2})
   if err != nil {
       log.Fatal(err)
   }
   for _, item := range page.Data {
       fmt.Println(item.Body)
   }
   ```
   :::

4. **Read the response.** A successful call returns `200 OK` and a list envelope:

   ```json
   {
     "data": [
       {
         "id": "fb_01J9ZK3Q7M",
         "body": "Export to CSV times out on large workspaces",
         "source": "support_ticket",
         "author": { "name": "Maria Santos", "email": "maria@northwind.example" },
         "theme_id": "thm_01J9Y2H8RA",
         "tags": ["export"],
         "created_at": "2026-10-06T14:22:09Z"
       }
     ],
     "has_more": true,
     "next_cursor": "eyJpZCI6ImZiXzAxSjlaSzNRN00ifQ"
   }
   ```

   `has_more` tells you whether another page exists, and `next_cursor` is what you pass back as `cursor` to fetch it. See [Pagination](doc:Pagination) for the details.

## If something goes wrong

A missing or malformed token returns `401`, and a token without the right scope returns `403`. Both bodies include a `request_id`; quote it if you contact support. The full list is in [Errors](doc:Errors).
