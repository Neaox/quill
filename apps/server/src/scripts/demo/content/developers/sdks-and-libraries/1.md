# SDKs and libraries

The official SDKs wrap the REST API with typed models, automatic [pagination](doc:Pagination), retries with backoff on `429` and `5xx`, and webhook signature helpers. All three follow the API's major version: SDK 2.x talks to `/v2`.

:::cards
### TypeScript

`@tidepool/sdk` 2.8.0. Node 20 or later, Deno and Bun. Ships ESM and CommonJS with full types.

```bash
pnpm add @tidepool/sdk
```

### Python

`tidepool` 2.6.1. Python 3.9 or later, with sync and `asyncio` clients built on `httpx`.

```bash
pip install tidepool
```

### Go

`github.com/acme-software/tidepool-go/v2` 2.5.0. Go 1.22 or later, context-aware, no dependencies outside the standard library.

```bash
go get github.com/acme-software/tidepool-go/v2
```
:::

## Behaviour they share

Every client reads the token from the `token` option or from `TIDEPOOL_TOKEN`, sends an `Idempotency-Key` on `POST` requests automatically, and retries up to 2 times by default. Set the retry count to `0` if you want to manage it yourself. Each client exposes `webhooks.verify` so you do not have to write the check from [Webhooks](doc:Webhooks) by hand.

For a language we do not cover, the API is plain JSON over HTTPS and the examples in this site translate directly.
