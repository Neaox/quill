# Release notes 2026.10

Released 6 October 2026. This release raises the Team plan's rate limits, adds token expiry, and tells you when a CSV import has finished.

## New

- :accent[New] **Token expiry.** Tokens can now carry an expiry date, up to 365 days ahead. Tokens created without one expire after 365 days. Workspace admins get an email 14 days before expiry, and an expired token returns `401` with the code `token_expired`. Existing tokens keep working until 12 October 2027. See [Authentication](doc:Authentication).
- :accent[New] **`import.completed` webhook.** Sent when a CSV import finishes, with `imported`, `skipped` and `failed` row counts. You no longer need to poll `GET /v2/imports/{id}`.
- :accent[New] **Sort themes by volume.** `GET /v2/themes?sort=-feedback_count` returns the themes with the most feedback first.
- :accent[New] **TypeScript SDK 2.8.0 and Python SDK 2.6.1.** Both add `webhooks.verify` support for several signatures at once, ready for secret rotation.

## Improved

- :ok[Improved] **Higher Team limits.** The Team plan now allows 600 requests per minute, up from 300, and 60 batch requests per minute, up from 30. Starter, Business and Enterprise are unchanged. See [Rate limits](doc:Rate limits).
- :ok[Improved] **Deliveries log.** **Settings → API → Webhooks → Deliveries** now keeps 30 days of history, up from 7, and can resend any event.

## Fixed

- :ok[Fixed] A `POST` retried with the same `Idempotency-Key` while the first request was still running could return `500`. It now returns `409` with the code `idempotency_in_progress`.
- :ok[Fixed] `feedback.updated` was sent twice when a theme assignment and a tag changed in the same request.

## Deprecated

- :warn[Deprecated] The `topic_id` field in v1 webhook payloads will stop being sent on 1 January 2027, with v1 itself.

## Known issues

- :bad[Open] `import.completed` can arrive before the last `feedback.created` events from the same import. Do not assume the import's items have all been delivered; fetch `GET /v2/feedback?import_id=...` to be sure. A fix is planned for 2026.11.

## Upgrading

No change is required. If you verify webhook signatures yourself, read the new section on rotating secrets in the [webhooks guide](doc:Webhooks) before you rotate.

:::details[Which SDK versions include the multiple-signature check?]
TypeScript 2.8.0 and later, and Python 2.6.1 and later. The Go SDK has accepted several `v1` values since 2.4.0, so Go 2.5.0 needs no update. If you pin an older version, upgrade before you rotate a signing secret.
:::

:::details[How do I see which of my tokens will expire?]
Open **Settings → API → Tokens** and sort by **Expires**. A token that was created before this release shows an expiry of 12 October 2027.
:::
