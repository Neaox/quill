# Data export and deletion requests

Customers ask for a copy of their data or for it to be deleted. Some cite GDPR, some are leaving, some are in the middle of a security review. Either way the clock starts when the request arrives: we must answer within 30 days, and we aim for 5 working days.

## Before you do anything

Confirm who is asking. Only a workspace owner can request an export or a deletion of workspace data. Check **Settings > Members** to see who the owners are. If the request comes from anyone else, ask them to have an owner reply from the owner's own address.

If the person is an individual whose feedback sits inside a customer's workspace, for example someone quoted in an interview, the customer is responsible for that data, not us. Point them to the workspace owner and add the `privacy-redirect` tag.

> [!WARNING]
> Harbourview Health and other healthcare customers may have patient details in their feedback. Never open an export file yourself. Send the link and nothing else.

## Exporting a workspace

1. Tag the ticket `data-request` and set the priority to High.
2. Verify the requester as above.
3. Ask the owner to use **Settings > Data > Export workspace**, or do it on their behalf from the admin console if they cannot. The export is a zip of CSV and JSON files, delivered by an email link that is valid for 7 days.
4. Exports under 50,000 feedback items usually finish within 15 minutes. Larger ones can take up to 4 hours. Above 500,000 items, post the workspace ID in #support-escalations so the platform team can run it off-peak.
5. Reply with the "Data export ready" macro from the [Support macros library](doc:Support macros library), and set the ticket to Pending.

## Deleting a workspace

1. Offer the export first. Deletion cannot be undone once the grace period ends.
2. Get written confirmation from an owner, from the owner's own address: "I confirm that Acme should delete the workspace [name]."
3. Check for a legal hold or an Enterprise retention clause in the order form. If either exists, stop and message Aisha Khan before doing anything else.
4. Cancel the subscription separately. Any refund follows the usual rules and is not part of the deletion.
5. Submit the deletion form in the admin console. The workspace is hidden at once and removed from the live database after 30 days. Backups age out a further 35 days later.
6. Tell the customer all three dates: hidden today, deleted on day 30, gone from backups on day 65. The owner can cancel the request at any time before day 30.

> [!WARNING]
> Never delete anything on the strength of an email that only says "please delete my data". Without owner confirmation in writing there is no deletion, however upset the customer is.

## What to record

Add a private note with the request date, the verifier, the export or deletion date and your name. Security audits ask for these, and the note is the only record support keeps. If anything is unclear, use the [Escalation matrix](doc:Escalation matrix) and ask early.
